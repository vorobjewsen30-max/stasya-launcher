# Stasya Launcher

Manage Minecraft Java instances with Microsoft sign-in, ownership checks, Modrinth content, automatic Java downloads and modpack imports.

Create separate Vanilla, Fabric, Quilt, Forge or NeoForge instances. Browse mods, modpacks, resource packs and shaders. The launcher selects the newest compatible publication and resolves the required dependencies declared by their authors. Import `.mrpack` files or add your own mod JARs.

Searchable instance menus open across their full button surface. Configure memory, toggle mods, read game output and repair downloaded resources.

The current application interface is Russian. A separate Minecraft: Java Edition license and personal Microsoft account are required. Minecraft and third-party mods are not bundled. Internet access and space for game resources are required. Shaders need a compatible renderer, such as Iris. Users must check compatibility and dependencies of manually imported JARs.

Independent project; not an official Mojang, Microsoft, Xbox or Modrinth product.
