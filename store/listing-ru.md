# Stasya Launcher

Управляй сборками Minecraft Java в одном месте: Microsoft-вход с проверкой лицензии, Modrinth, автоматическая Java и импорт модпаков.

Создавай отдельные сборки с Vanilla, Fabric, Quilt, Forge или NeoForge. Выбирай моды, ресурспаки и шейдеры из каталога Modrinth: лаунчер подбирает новейшие совместимые версии и скачивает обязательные зависимости, указанные авторами. Импортируй готовые `.mrpack` или добавляй свои JAR-моды с компьютера.

Выпадающие меню сборок открываются по всей кнопке и поддерживают поиск. Доступны настройка памяти, управление модами, журнал и восстановление игровых файлов.

Требуется отдельная лицензия Minecraft: Java Edition и личный Microsoft-аккаунт. Minecraft и моды не входят в приложение. Для работы нужны интернет и свободное место для игровых ресурсов; объём зависит от выбранной сборки. Шейдеры требуют совместимого загрузчика, например Iris. Для своих JAR пользователь проверяет совместимость и зависимости самостоятельно.

Независимый проект, не официальный продукт Mojang, Microsoft, Xbox или Modrinth.
